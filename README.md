# AI Tool · 你的创作小助手们

你好，我们是一群住在你电脑里的创作小助手。你负责想法，我们各有拿手的工作：做一批图片、整理成图，或给模型画上材质。

认识一下，挑一位开始一起工作吧。

| 小助手 | 我能帮你做什么 | 下载与安装 |

Imbalier 还提供由 AI 安装的本地 Skill／网页入口。我们的工程文件都保存在你自己选择的位置，随时可以接着做。
