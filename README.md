# AI Tool

一套面向创作的本地工具。每款工具独立安装，工作文件保存在你选择的位置。

## 工具

| 工具 | 用途 | 入口 |
|---|---|---|
| Batch Image Foundry · 批量生图 | 批量制作图片，统一提示词与参考图，整理历史并导出成图。 | [介绍与下载](https://github.com/EspalierLin/ai-tool-releases/tree/101-batch-image-foundry) |
| 3D Asset Shader · 3D资产Shader制作 | 在模型和 UV 上联动绘画，生成、分层精修并导出模型材质。 | [介绍与下载](https://github.com/EspalierLin/ai-tool-releases/tree/pixel-texture-painter) |

在工具页面选择桌面安装包，或复制介绍文字，让 AI 安装本地 Skill 与完整网页。下载直接指向对应附件，无需克隆仓库。
