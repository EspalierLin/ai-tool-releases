# Batch Image Foundry

按任务批量生成图片，保存提示词、参考图、结果与历史，筛选后导出。

类型：桌面应用；公共更新首个接入示例。本分支承载此工具的介绍、发行说明与下载索引；安装材料存放在本分支对应标签的 Release 附件。
