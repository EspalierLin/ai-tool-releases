# Batch Image Foundry

按任务批量生成图片，保存共享提示词、参考图、结果与历史，筛选后导出。

本分支维护工具介绍、版本索引和下载入口，大包存放于工具标签对应的 Release 附件。

**公共更新功能已接入。当前尚无取得正式发行资格的公开附件；源码能力、内部候选和已验签不等于正式发布或安装完成。**

## 使用与更新

安装正式包后，使用自己的账号和资源。设置菜单提供检查更新；发现可信新版本会显示提醒。应用和已配置公开来源的插件分别比较版本，先下载并校验签名、长度和摘要，再安装。

新 Windows 安装宿主在本人确认、保存草稿和安全退出后交接安装；旧宿主、便携版与 macOS 保存已验证安装包后手动安装。新应用以实际运行版本确认完成，失败走安全恢复。外置账号、工程、图片和插件保留；工程格式转换是独立动作。

插件更新需审阅当前／新版权限，批准后在原插件管理启用。原来禁用的插件保持禁用，握手失败保留旧版本。内部插件、作者凭据和用户作品不进入本仓库或嵌套应用。

旧应用没有更新入口，必须先手动安装一次含该能力的版本。GitHub 自动生成的 Source code ZIP/TAR 只是此分支文档快照。

## 版本与来源

应用身份为软件版本加 Package 构建号，插件使用自己的版本。发布标签带本工具分支前缀，不以仓库全局 latest 判断本工具更新。当前没有公开 stable/preview 签名头，索引中的渠道为空；更新检查会准确显示尚无公开版本。
