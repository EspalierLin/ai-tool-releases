# Batch Image Foundry · 批量生图

把一批图片的制作、整理和导出放在同一个工作文件里。

- 用共享提示词和参考图统一画风，逐项设置任务并批量生成。
- 查看当前图片和历史结果，用颜色标签、筛选和表格整理任务。
- 按任务设置导出比例，导出所选成图；工程保存图片、设置和历史。

## 安装与使用

Windows 下载后运行安装 EXE；Mac 打开 DMG，将应用拖入“应用程序”。使用自己的 AI 账号，创建或打开 `.elproject` 工程后开始工作。

更新入口在“设置 → 检查更新”。Mac 下载更新包后手动安装；工程、图片和已安装插件保留。公司插件按其独立授权安装。
